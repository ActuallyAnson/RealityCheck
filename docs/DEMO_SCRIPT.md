Every number spoken here is in `README.md` or `docs/SCAN.md` (generated by scripts in this repo). Do not add numbers that are not there. Record the terminal at a large font; the commands below were run on this repo (the tank scan takes about 6 seconds).

Setup before recording (not on camera): `cmake -S . -B build && cmake --build build -j`, close other windows, clear the terminal, `export` nothing (the first two parts need no key).

## Commands

A. adapter-free scan (needs no key):

    ./build/rc_scan --cmd "./build/generic_tank_cli --inflow {inflow} --demand {demand} --capacity {capacity} --frac {setpoint_fraction} --gain {gain} --mode {mode} --steps {steps} --seed {seed}" --param inflow:0:8 --param demand:0:4 --param capacity:5:60:int --param setpoint_fraction:0.1:0.9 --param gain:0.1:8:log --choice mode:proportional,bang_bang --scenarios 400 --out scan_demo
    open scan_demo/report.html

B. viewer: `./build/rc_demo`, then open the printed local address. Live agent runs need `MODEL_API_KEY` in the environment; do not show the key or the shell profile on screen. If the live call is slow or fails, use the stored replay (the Oracle gap and replay views need no key).

## Rules for the recording

- Do not show any API key, the shell profile, or the spend ledger path contents.
- Do not claim a bug in anyone's code, only "reproducible hang, not reported upstream, may be known".
- Do not say "finds bugs automatically". Say "notices behavior changes of some kinds; here is what it misses".
- If a command output differs from this script, say what you see, not what the script says.
- Keep it under 3 minutes; cut part 4 first if long.
