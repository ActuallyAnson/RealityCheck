# Externally sourced scenarios

Scenarios taken from the literature and from standard practice, not generated by this repository's samplers. Each file carries a `_source` field
saying where it comes from and what had to be adapted to the domain's limits (positions shifted into the arena, lengths scaled, the domain's
softened gravity). Run them all with `./build/rc_corpus [--rebound PATH]`; the output of the last run is `results/rebound/corpus.md`.

- **orbit** (G = 1): Kepler two-body circular and eccentric (textbook, vis-viva); figure-eight three-body choreography (Chenciner and Montgomery 2000, initial
  conditions as tabulated by Simo 2002 and Suvakov and Dmitrasinovic 2013; scaled); Pythagorean three-body problem (Burrau 1913; Szebehely and Peters 1967);
  Lagrange's equilateral solution; a heavy star with three light bodies on circular-speed orbits.
- **rigid2d:** Newton's cradle, a bouncing ball, a billiard break, a three-disc pyramid on a ledge (classic engine test scenes; written for this domain, not copied from any engine's test suite).
- **cartpole:** the classic benchmark constants (Barto, Sutton and Anderson 1983; OpenAI Gym CartPole), with and without noise and a disturbance. The controller is this repository's.
- **traffic:** a conventional fixed-time two-phase plan and a semi-actuated plan with the event mix of a real controller (values typical of practice; not taken from one document).

I wrote the initial conditions from these sources myself (derivations such as speeds for circular orbits are in the generating arithmetic of each `_source`);
no file is a download. Where the domain differs from the source (the softened force law), the scenario is a stress input, not a reproduction of the published result.
